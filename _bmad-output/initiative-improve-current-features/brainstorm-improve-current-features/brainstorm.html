02 / technique · 22 ideas

Job to Be Done

Nobody wants a screenshot; they want the thing the screenshot does. Six jobs were named, each pinned here with a counter mark the way you would number steps on a capture.

1Report a bug with evidence

  • Bug-report bundle: capture plus an auto-attached context block (app, window title, display, macOS) copied alongside
  • Copy as Markdown (image + caption) for GitHub/Jira paste
  • Auto-redact: detect emails, tokens, IBANs, phone numbers via Vision text + patterns, one click to blur. Matters for a fintech/regtech company
  • Copy as file vs copy as image choice for apps that drop pasted images
  • GIF size target ("under 10 MB for Jira") on Stop-as-GIF

2Explain how to do X

  • Numbered-steps text generated from counter marks ("1. Click X"), editable, copied with the image
  • Multi-capture storyboard: take 3-5 shots in a row and combine into one strip for how-to explanations
  • Keystroke overlay in recordings so how-to videos show the shortcuts pressed
  • Recording auto-dims everything but the active window
  • Post-record annotation: add arrows/text to segments in the Trim panel
  • Recording markers: a key drops a chapter marker; Trim snaps to markers
  • Scrolling capture of long pages/lists
  • Visible self-timer countdown for delayed captures

3Get design feedback

  • Eyedropper in the editor with hex copy (ruler exists; add colour)
  • Editable sidecar: saved PNG reopens with its marks still editable

4Show progress

  • Onion-skin compare: overlay two captures with an opacity slider for before/after
  • Recording presets by purpose: Jira bug (720p/15fps small) vs Demo (1080p60)

5Keep a reference visible

  • Pin click-through mode: translucent pin you can trace/align UI against
  • Pin opacity slider and lock

6Grab text

  • Copy-text capture mode straight from the selection overlay, no editor (OCR exists)
  • History search by the text inside captures (OCR index)
  • History search by app/window title recorded at capture time (xattr metadata)

The six jobs come from the session; which job each idea is pinned to is this keepsake's own filing.

05 / technique · 18 ideas

Crank the Dial to 11 + Kill the Crown Jewel

Two provocations in one round. Turn speed up until capture-to-shared takes under 1 s, then kill the crown jewels: imagine m_capture with no editor and no hotkeys.

The dial: speed

Goal: capture-to-shared under 1 s

  • hotkeyMeasure hotkey-to-overlay latency and hold a <100 ms budget (warm-up exists, unmeasured)
  • editorPre-create the editor window off-screen to cut open latency
  • overlayOne-key actions from the overlay: C copy+close, S save, P pin. No editor
  • repeatRepeat last window capture, not just last region
  • recordInstant-record modifier that skips the countdown
  • gifGIF export progress + cancel, faster frame generation
  • historyOn-disk thumbnail cache so History opens instantly with thousands of files

Kill the crown jewel

No EDITOR  ·  no HOTKEYS

With no editor

  • Auto-box the UI element under the cursor at capture time
  • Region edges snap to UI element boundaries (magnetic edges)
  • Auto zoom callout around the cursor

With no hotkeys: bring images in

  • Drop an image on the menu-bar icon to annotate it
  • Open any existing image in the editor (Open..., Services "Annotate with m_capture")
  • Shortcuts.app / App Intents actions: capture region, annotate image
  • URL scheme mcapture://capture?mode=window for Raycast/Alfred/scripts
  • Annotate-clipboard hotkey
  • CLI: m_capture --capture region --out path for automation

Shaken loose on the way

  • Privacy guard: warn or auto-blur when capturing password managers or banking apps
  • On-device Apple Foundation Models to draft step descriptions / alt text, no network speculative · macOS 26
